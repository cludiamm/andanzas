# Competitive Analysis

First pass, based on research from August 2026 — pricing and features change,
revisit periodically rather than treating this as fixed.

| App | Pricing | Core strength | Gap vs. Andanzas |
|---|---|---|---|
| Wanderlog | Free / Pro $40/yr | Real-time collaborative map-based itinerary; generous free tier | Itinerary tool only — no finance/reservations vault, no opinionated "why this place" curation |
| TripIt | Free / Pro $49/yr | Best-in-class for organizing bookings you already made (flight alerts, etc.) | Purely a booking organizer — doesn't help you decide where to go or vote as a group |
| Layla AI | $49/yr (3-day trial) | AI-generated full itineraries with live pricing | Generic AI output; no personal curation methodology or group decision-making |
| Mindtrip | Freemium | Strongest group features (shared itinerary + group chat); agentic AI flight booking; community guides | Broad AI-assistant scope dilutes a "slow down, appreciate the place" positioning |
| Roadtrippers | Freemium | Road-trip route intelligence trained on 38M+ planned trips | Road-trip-specific niche; not built for international, multi-stop trips |
| Vacay | From $9.99/mo | Personalized recommendations, real-time updates | Point solution for recommendations, not full trip lifecycle |
| Troupe / WePlanify / MonkeyTravel | Free / freemium | Purpose-built group voting: suggest places, vote, reach consensus, split budget | Built for the vote itself, not the deeper curation of *what's worth voting on* — no solo mode |

## Where the gap is

**Fragmentation.** Every competitor above is a point solution — itinerary
mapping OR booking storage OR group voting OR AI recommendations. Nobody
stitches transport, curated place options, group voting, finance, and
reservations into one flow.

**Curation vs. generation.** AI trip planners (Layla, Mindtrip) generate
itineraries from generic training data. Andanzas' edge is a field-tested
methodology built from real trips, not an AI guessing at what's good.

**Solo + group, one system.** Group-voting apps serve groups only. None
double as a solo trip-planning companion using the same underlying model.

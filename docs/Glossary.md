# Glossary

- **JTBD (Jobs to be Done)**: the underlying job a customer "hires" a
  product to do, independent of category.
- **MVP**: the minimum feature set needed to test the core value
  proposition — here, curated place voting.
- **Consensus vote**: when a group votes on a place option and a result is
  surfaced (e.g. most votes wins) rather than requiring unanimous agreement.
- **Working name**: Andanzas — provisional but locked in for this sprint.

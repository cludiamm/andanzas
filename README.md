# Andanzas

A trip-planning app for people who want to be part of planning their trip
without doing all the research themselves — curated place options, plus
group or solo voting, instead of a rushed agency itinerary.

**[Try the live demo →](https://andanzas-trip-planner.replit.app/)**

Built as a fast-prototyping exercise (Claude for strategy/specs, Replit
Agent for the build) and as the seed of a real product.

Read the [case study](docs/09-case-study/case-study.md) for the problem,
process, and key decisions, or `docs/` for the full strategy, research,
and specs behind it.
